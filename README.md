# My_App: сайт

Статический сайт (описание, тарифы, скачивание, оплата). Исходный код программы здесь не хранится.
Публикуется через GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.

Перед публикацией заполните: `config.js` (контакты, ссылки на скачивание), `offer.html` и `privacy.html` (жёлтые поля).
